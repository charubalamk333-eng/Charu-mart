
# Charu Mart — E-Commerce Frontend

## Project Overview
Charu Mart is an e-commerce website frontend designed to provide users with an interface for browsing products and accessing shopping features.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Customer login and registration pages
- Product browsing interface
- Search functionality
- Customer, seller, and admin login pages
- Backend API integration

## Project Files
- `index.html` — Main entry page
- `home.html` — Product browsing page
- `login.html` — Login page
- `register.html` — Registration page
- `register.js` — Registration functionality
- `script.js` — Frontend interactions
- `style.css` — Website styling
- `admin-login.html` — Admin login page
- `seller-login.html` — Seller login page
